# Iowa City Game Day Guide
Fictional educational website for MKTG:4400. Four pages built with static HTML and CSS.

## Publishing
Upload `index.html`, `parking.html`, `food.html`, `traditions.html`, `style.css`, `robots.txt`, and `sitemap.xml` to the root of a public GitHub repository. Before publishing, replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in `robots.txt` and `sitemap.xml` with your actual GitHub username and repository name. In repository Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`, and Save.

`build.py` is the optional source generator; the HTML files are already generated and ready to upload.

Check all current parking, transit, dining, and stadium rules against official sources before relying on them. The site is an educational fictional project.
